# AXOVYN

AXOVYN neural guardian frontend for Solana: animated brain and vascular data flow, pointer-following eyes, signal monitoring, error isolation, a token watchlist and a SOL paper-account panel.

## Publish with GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The frontend requires no build step or package installation. Set your custom domain in the same Pages settings when ready.

## Files

- `index.html`: page, styling and animation logic.
- `assets/guardian.png`: neural guardian artwork.
- `.nojekyll`: serve this as a plain static site.

## Behavior

The monitoring, token decisions, P&L and SOL allocation panels are an illustrative local replay. This frontend has no live trading connection and performs no wallet transactions. The on-page replay disclosures remain visible.
